# Трекер расходов

Личный учёт расходов и доходов в виде веб-приложения (PWA — сайт, который ставится на экран «Домой» и работает как приложение, в том числе без интернета).

- **Без сервера и бесплатно.** Код лежит на GitHub Pages, данные хранятся на устройстве.
- **«База данных» — второй, приватный репозиторий.** Приложение хранит там файл `data.json` и синхронизирует его между телефоном и компьютером. История коммитов заодно служит бэкапом.
- **Рубли, суммы с копейками.** Светлая и тёмная тема подстраиваются под систему.

## Что умеет

- **Расходы и доходы**: сумма, категория, дата, комментарий. Правка, удаление с кнопкой «Вернуть».
- **Категории**: 15 базовых для расходов и 5 для доходов. Можно добавить свою прямо из формы операции, переименовать, сменить эмодзи или удалить (старые операции при этом сохраняются).
- **Аналитика за месяц**: расходы, доходы и остаток; сравнение с теми же днями прошлого месяца; средний расход в день; разбивка по категориям (тап открывает операции категории); график по дням; последние 6 месяцев; самые крупные траты.
- **Регулярные платежи**: подписки, аренда, связь, зарплата — раз в месяц или раз в год. Операции записываются сами в день платежа (с пометкой 🔁), пропущенные дни догоняются, дублей не бывает.
- **Быстрые кнопки** над списком операций: «☕ Кофе 250 ₽» — запись в одно касание (с кнопкой «Отменить»), «🚇 Метро 60–240 ₽» — выбор суммы.
- **Долги**: «мне должны» и «я должен», срок возврата, частичные возвраты, просроченные сверху с красной точкой на вкладке, кнопка «Напомнить» (готовое сообщение через «Поделиться»). Долги не смешиваются с расходами.
- **Выгрузка для ИИ**: файл `.md` за любой период (по умолчанию текущий месяц, есть «прошлый месяц», «3 месяца», «с начала года» и свои даты «с … по …»). Внутри уже есть задание для нейросети, сводка, категории, динамика по неделям/месяцам и дням недели, топ трат и **все операции в CSV**. Файл можно закинуть в ChatGPT, Claude, DeepSeek или GigaChat. Переключатели позволяют убрать комментарии или доходы и добавить долги (без имён).
- **Выгрузка в Excel/CSV** за те же даты: разделитель `;`, суммы с запятой, кириллица читается корректно.
- **PIN-код и Face ID / Touch ID** (подробности ниже).
- **Резервная копия** в JSON и восстановление из неё.

## 1. Публикация на GitHub Pages (один раз)

1. **Сделай этот репозиторий публичным** (Settings → General → Danger Zone → Change visibility). На бесплатном тарифе GitHub Pages работает только для публичных репо. Публичным становится только код: твои траты сюда не попадают.
2. **Settings → Pages → Source: GitHub Actions.**
3. Основная ветка репозитория должна быть `main` (Settings → General → Default branch). Workflow публикует сайт только из основной ветки, в остальных ветках гоняются тесты.
4. Влей изменения в `main` (или запусти вручную: **Actions → Tests & Deploy → Run workflow**) и дождись зелёной галочки.
5. Сайт появится по адресу `https://<логин>.github.io/trecker_rashody/`.

Если деплой упал на шаге `configure-pages`, значит не выполнен пункт 2.

## 2. Установка на айфон

1. Открой ссылку **в Safari** (не в Chrome и не во встроенном браузере Telegram).
2. «Поделиться» → **«На экран „Домой“»** → «Добавить».
3. Запускай приложение с иконки.

> ⚠️ У Safari и у приложения с экрана «Домой» **разные хранилища**. Данные, добавленные в Safari, не появятся в установленном приложении, пока не включена синхронизация.

## 3. «База данных» во втором репозитории (синхронизация)

1. Создай **приватный** репозиторий, например `trecker-data`: <https://github.com/new> → **Private**, отметь **Add a README file**.
2. Создай fine-grained токен: <https://github.com/settings/personal-access-tokens/new>
   - Repository access → **Only select repositories** → `trecker-data`;
   - Permissions → Repository → **Contents: Read and write** (больше ничего не нужно);
   - Expiration: **Custom** на год вперёд (или **No expiration** — удобнее, но утёкший токен будет работать, пока его не удалишь). Короткие сроки (7–90 дней) не бери: синк будет регулярно отваливаться.
3. В трекере (удобнее на компьютере): **Настройки → Синхронизация через GitHub** → введи `логин/trecker-data` и токен → «Подключить».
4. **Второе устройство — по QR-коду.** На подключённом: Синхронизация → **«Подключить другое устройство»** → «Показать QR-код». На телефоне (трекер открыт с иконки): Настройки → Синхронизация → **«📷 Сканировать QR-код»**. Без камеры: «Скопировать ключ текстом» на одном устройстве и «Вставить ключ подключения» на другом.

> ⚠️ В QR-коде и ключе — токен. Не делай скриншот и не пересылай ключ в чаты. QR прячется сам через 2 минуты.

**Как работает.** При открытии приложения, через ~1,5 с после любой правки и раз в минуту (пока приложение открыто) устройство читает `data.json`, сливает его со своими данными и при необходимости записывает обратно. Каждая запись — отдельный коммит. Без интернета всё работает и догоняется позже.

**Конфликты.** У каждой записи есть время изменения, побеждает более свежая версия. Удаление хранится как «надгробие», поэтому удалённое на телефоне не воскреснет с компьютера. Если два устройства пишут одновременно, GitHub отклоняет устаревшую запись (проверка `sha`), и приложение перечитывает файл и сливает заново.

**Безопасность.**
- Публичный репозиторий приложение не примет.
- Токен хранится только на твоих устройствах и даёт доступ к одному репозиторию и только к файлам. Если токен утёк, удали его в GitHub → Settings → Developer settings → Personal access tokens и создай новый.
- Все сайты GitHub Pages одного аккаунта живут на одном домене `<логин>.github.io`. Не публикуй там чужой или непроверенный код: технически он сможет прочитать данные трекера.

## 4. PIN-код и Face ID

**Настройки → Защита → Поставить PIN-код.** После этого приложение спрашивает PIN при запуске и после сворачивания (сразу, через 1, 5 или 15 минут). Пока приложение свёрнуто, экран размыт, чтобы суммы не попали в превью переключателя приложений.

- **Face ID / Touch ID** включается переключателем под PIN-кодом. Система сохранит ключ входа (passkey) в «Пароли». На экране блокировки нажми значок лица на клавиатуре. Если не сработало, введи PIN.
- Хранится только хэш PIN (PBKDF2 с солью), сам PIN нигде не записан. У каждого устройства свой PIN, в синхронизацию он не попадает.
- После 5 неверных попыток ввод замораживается на 30 секунд, дальше пауза удваивается (максимум час). Перезапуск паузу не сбрасывает.
- **Забыл PIN** → «Забыли PIN?» → данные **этого устройства** стираются. С синхронизацией они вернутся из GitHub после повторного подключения, без неё — только из резервной копии.
- ⚠️ **Это защита от человека, который взял твой разблокированный телефон, а не шифрование.** Данные и токен на устройстве лежат открыто: тот, у кого есть доступ к компьютеру и инструментам разработчика браузера, сможет их прочитать.

## 5. Регулярные платежи и быстрые кнопки

**Настройки → Автоматизация.**

- **Регулярный платёж**: сумма, название («Яндекс Плюс»), категория, «раз в месяц» или «раз в год» и дата первого платежа. Если дата в прошлом, прошедшие платежи запишутся сразу (форма заранее скажет, сколько). 31-е число в коротком месяце превращается в последний день месяца.
  - Операции появляются, когда приложение открыто. Каждой соответствует один месяц (или год) правила, поэтому телефон и компьютер не создадут дубль. Удалённая операция не вернётся.
  - **Пауза** останавливает записи; после возобновления пропущенное не догоняется. **Удаление** правила оставляет уже записанные операции.
  - В выгрузке для ИИ есть отдельная таблица регулярных платежей с пересчётом на месяц.
- **Быстрая кнопка**: эмодзи, подпись, категория и одна или несколько сумм. Созданные кнопки стоят над списком операций (пока их нет — ряда тоже нет). Добавлять и менять — в Настройки → Автоматизация → Быстрые кнопки. Случайный двойной тап дубль не создаёт.

## 6. Выгрузка для ИИ

**Аналитика → «🤖 Выгрузить для ИИ»** (или Настройки → Выгрузка):
1. выбери период: чипы или даты «С» и «По»;
2. на телефоне нажми «Сохранить или отправить файл». Откроется меню «Поделиться», откуда файл можно сразу отправить в приложение ChatGPT/Claude или сохранить в «Файлы». На компьютере файл просто скачается;
3. прикрепи файл в чат с нейросетью и отправь. Задание уже внутри файла, можно дописать свой вопрос.

«Скопировать текстом» кладёт то же самое в буфер обмена, чтобы вставить прямо в чат.

## Резервные копии

Без синхронизации данные живут только на одном устройстве: удалишь иконку или очистишь данные сайтов, и всё пропадёт. Поэтому:
- **Настройки → Сохранить копию** — JSON-файл (на телефоне через «Поделиться» → «Сохранить в Файлы»);
- **Настройки → Восстановить из копии** — заменяет данные на устройстве данными из файла;
- если есть 15+ операций, синхронизация выключена и копии не было больше месяца, приложение само напомнит.

## Обновления

После каждого деплоя в `main` приложение на телефоне обновится само при следующем запуске с интернетом (иногда нужно открыть его дважды). Версия сборки видна внизу экрана «Настройки».

## Разработка

```bash
npm start   # http://localhost:8080 (без офлайн-кэша, правки видны сразу)
npm test    # тесты логики, синхронизации, PIN, QR, целостности файлов
```

Сборки и зависимостей нет: чистые HTML/CSS/JS-модули.

## Ограничения

- Одна валюта — рубли.
- Синхронизация не мгновенная: изменения с другого устройства приходят в течение минуты (или сразу по кнопке «Синхронизировать сейчас»).
- Регулярные платежи записываются, только когда приложение открыто: не открывал месяц — все пропущенные появятся разом при следующем запуске.
- Сканер QR на айфоне работает через библиотеку jsQR (встроенного распознавания в Safari нет); если камера недоступна — есть вставка ключа текстом.
